X Feed Cleaner hides the parts of X.com built to pull you in — the algorithmic
timeline, trends and live content — so you can use it for what you came for
without falling into a scroll. It has 200+ weekly users.

## How it works

The hiding is driven by a `MutationObserver` so it holds up through infinite
scroll and live updates, and it's written in plain vanilla JavaScript to keep
the memory footprint minimal. A small popup lets you toggle each filter on or
off, and your choices persist through Chrome Storage. It's privacy-first —
ad-free, local, zero tracking — and fully open-source.

Try it via the [landing page](https://x-feed-cleaner.carrd.co/) or read the code
on [GitHub](https://github.com/BaskLash/X-Feed-Cleaner). It's also on the Chrome
Web Store as _X (Twitter) Cleaner_.
